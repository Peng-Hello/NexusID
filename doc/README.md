## 🎯 项目目标

在2周内完成一个生产级别的SSO平台，支持：
- ✅ OpenID Connect (OIDC) 协议
- ✅ 用户注册/登录/管理
- ✅ RBAC权限控制
- ✅ 管理后台
- ✅ 完整的API文档
- ✅ Docker部署方案
