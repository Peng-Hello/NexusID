# 安全指南

## 🔐 密码安全

### 密码策略
- **最小长度**: 8个字符
- **复杂度要求**:
  - 至少包含一个大写字母
  - 至少包含一个小写字母
  - 至少包含一个数字
  - 至少包含一个特殊字符
- **常见密码检查**: 拒绝常见弱密码
- **密码历史**: 不允许重复使用最近5次密码

### 密码存储
```go
// 使用bcrypt加密，cost factor = 10
cost := 10
hashedPassword, err := bcrypt.GenerateFromPassword([]byte(password), cost)
```

### 密码重置流程
1. 用户请求重置密码
2. 系统发送包含重置token的邮件
3. Token有效期: 1小时
4. 用户使用token设置新密码
5. Token使用后立即失效

### 防暴力破解
- **登录限流**: 5次失败后锁定15分钟
- **IP限流**: 单IP每分钟最多10次登录尝试
- **账户锁定**: 连续10次失败后锁定账户1小时

## 🎫 Token安全

### JWT配置
```yaml
jwt:
  access_token_expire: 3600      # 1小时
  refresh_token_expire: 2592000  # 30天
  signing_algorithm: RS256       # 使用RS256更安全
  issuer: "http://localhost:8080"
```

### Access Token
- **有效期**: 1小时
- **签名算法**: RS256 (非对称加密)
- **包含Claims**:
  ```json
  {
    "iss": "http://localhost:8080",
    "sub": "user_id",
    "aud": "client_id",
    "exp": 1234567890,
    "iat": 1234567890,
    "scope": "openid profile email"
  }
  ```

### Refresh Token
- **有效期**: 30天
- **存储**: 数据库 (hash后存储)
- **单次使用**: 使用后生成新的refresh token
- **撤销机制**: 支持主动撤销

### ID Token
- **符合规范**: OpenID Connect规范
- **包含用户信息**:
  ```json
  {
    "iss": "http://localhost:8080",
    "sub": "user_id",
    "aud": "client_id",
    "exp": 1234567890,
    "iat": 1234567890,
    "email": "user@example.com",
    "email_verified": true,
    "name": "John Doe"
  }
  ```

### Token黑名单
使用Redis实现token黑名单:
```go
// Token撤销时添加到黑名单
redis.Set(ctx, "blacklist:"+tokenID, "1", time.Until(expiresAt))
```

## 🌐 OIDC安全

### PKCE (Proof Key for Code Exchange)
防止授权码拦截攻击:
```
code_challenge = BASE64URL(SHA256(code_verifier))
code_challenge_method = S256
```

### State参数
防止CSRF攻击:
```go
// 生成随机state
state := generateRandomString(32)
session.Set("oauth_state", state)
```

### 重定向URI验证
- **严格匹配**: 重定向URI必须完全匹配注册的URI
- **白名单机制**: 只允许预注册的回调地址
- **HTTPS要求**: 生产环境强制HTTPS

### 客户端认证
- **Confidential Client**: 使用client_secret认证
- **Public Client**: 使用PKCE，不需要secret
- **Secret存储**: 使用bcrypt hash存储

## 🛡️ 传输安全

### HTTPS配置
```nginx
server {
    listen 443 ssl http2;
    server_name sso.example.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    # 推荐配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
}
```

### HTTP安全头
```go
func SecurityHeaders() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Header("X-Frame-Options", "DENY")
        c.Header("X-Content-Type-Options", "nosniff")
        c.Header("X-XSS-Protection", "1; mode=block")
        c.Header("Strict-Transport-Security", "max-age=31536000; includeSubDomains")
        c.Header("Content-Security-Policy", "default-src 'self'")
        c.Header("Referrer-Policy", "strict-origin-when-cross-origin")
        c.Next()
    }
}
```

## 🔒 输入验证

### SQL注入防护
使用GORM的参数化查询:
```go
// ✅ 正确
db.Where("email = ?", email).First(&user)

// ❌ 错误 - 易受SQL注入
db.Where("email = '" + email + "'").First(&user)
```

### XSS防护
```go
// 输入时转义
import "html"

escaped := html.EscapeString(userInput)
```

### CSRF防护
```go
// 使用CSRF Token
func CSRFMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := c.GetHeader("X-CSRF-Token")
        if !validateCSRFToken(token) {
            c.AbortWithStatus(403)
            return
        }
        c.Next()
    }
}
```

## 🚦 限流机制

### 基于Redis的限流
```go
func RateLimitMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        key := "rate_limit:" + c.ClientIP()
        count, _ := redis.Incr(ctx, key).Result()
        if count == 1 {
            redis.Expire(ctx, key, time.Minute)
        }
        if count > 100 { // 每分钟100次
            c.AbortWithStatusJSON(429, gin.H{"error": "Too many requests"})
            return
        }
        c.Next()
    }
}
```

### 分级限流策略
| 端点类型 | 限制 |
|---------|------|
| 登录 | 10次/分钟/IP |
| API调用 | 100次/分钟/IP |
| OIDC授权 | 20次/分钟/用户 |

## 🔐 会话管理

### 会话存储
使用Redis存储会话:
```go
sessionKey := fmt.Sprintf("session:%s", sessionID)
sessionData := map[string]interface{}{
    "user_id": userID,
    "expires_at": time.Now().Add(24 * time.Hour),
}
redis.HMSet(ctx, sessionKey, sessionData)
```

### 会话过期
- **空闲超时**: 24小时无操作自动过期
- **绝对超时**: 7天强制过期
- **记住登录**: 30天过期

### 单点登出
```go
// 撤销所有refresh token
func LogoutAllSessions(userID int64) error {
    return db.Where("user_id = ? AND revoked_at IS NULL", userID).
        Update("revoked_at", time.Now()).Error
}
```

## 📝 审计日志

### 记录内容
- 用户登录/登出
- 权限变更
- 敏感操作
- API调用失败

### 日志格式
```go
type AuditLog struct {
    UserID     int64           `json:"user_id"`
    Action     string          `json:"action"`
    Resource   string          `json:"resource"`
    Details    json.RawMessage `json:"details"`
    IPAddress  string          `json:"ip_address"`
    UserAgent  string          `json:"user_agent"`
    CreatedAt  time.Time       `json:"created_at"`
}
```

### 日志保留
- **在线日志**: Redis保留7天
- **归档日志**: 数据库保留1年
- **敏感信息**: 密码等字段不记录

## 🆘 安全事件响应

### 数据泄露处理流程
1. **确认**: 确认泄露范围和影响
2. **遏制**: 立即撤销受影响账户的token
3. **通知**: 通知受影响用户
4. **调查**: 分析原因，修复漏洞
5. **预防**: 改进安全措施

### 密码重置建议
- 强制所有用户重置密码
- 启用额外的身份验证
- 监控异常活动
- 审查访问日志
