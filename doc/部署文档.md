# 部署文档

## 📋 前置要求

### 开发环境
- Go 1.21+
- MySQL 8.0+
- Redis 7.0+
- Git
- Make (可选)

### 生产环境
- Docker & Docker Compose
- Nginx
- SSL证书

## 🚀 本地开发

### 1. 克隆项目
```bash
git clone https://github.com/your-org/nexus-id.git
cd nexus-id
```

### 2. 安装依赖
```bash
go mod download
```

### 3. 配置环境
```bash
# 复制配置文件
cp configs/config.yaml configs/config.local.yaml

# 编辑配置文件
vim configs/config.local.yaml
```

### 4. 启动依赖服务
```bash
# 使用Docker启动MySQL和Redis
docker-compose -f docker/docker-compose.dev.yml up -d
```

### 5. 数据库迁移
```bash
# 运行迁移
make migrate
# 或
go run cmd/migrate/main.go up
```

### 6. 初始化数据
```bash
# 创建默认管理员账户
go run cmd/seed/main.go
```

### 7. 启动服务
```bash
# 使用Make
make run

# 或直接运行
go run cmd/server/main.go
```

服务将在 http://localhost:8080 启动

## 🐳 Docker部署

### 构建镜像
```bash
docker build -t nexus-id:latest .
```

### 使用Docker Compose
```bash
# 启动所有服务
docker-compose -f docker/docker-compose.yml up -d

# 查看日志
docker-compose -f docker/docker-compose.yml logs -f

# 停止服务
docker-compose -f docker/docker-compose.yml down
```

### 环境变量配置
```bash
# docker-compose.yml
environment:
  - SSO_SERVER_MODE=release
  - SSO_SERVER_PORT=8080
  - SSO_DATABASE_HOST=mysql
  - SSO_DATABASE_PORT=3306
  - SSO_DATABASE_USERNAME=sso_user
  - SSO_DATABASE_PASSWORD=secure_password
  - SSO_DATABASE_NAME=sso_platform
  - SSO_REDIS_HOST=redis
  - SSO_REDIS_PORT=6379
  - SSO_JWT_SECRET=your-jwt-secret-key
  - SSO_JWT_ISSUER=https://sso.example.com
```

## 🌐 生产部署

### 1. 服务器准备

#### 系统要求
- Ubuntu 20.04+ / CentOS 8+
- 2核 CPU
- 4GB 内存
- 50GB 磁盘

#### 安装Docker
```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 安装Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

### 2. SSL证书配置

#### 使用Let's Encrypt
```bash
# 安装certbot
sudo apt install certbot

# 获取证书
sudo certbot certonly --standalone -d sso.example.com

# 证书路径
# /etc/letsencrypt/live/sso.example.com/fullchain.pem
# /etc/letsencrypt/live/sso.example.com/privkey.pem
```

### 3. Nginx配置

```nginx
# /etc/nginx/sites-available/nexus-id
server {
    listen 80;
    server_name sso.example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name sso.example.com;

    ssl_certificate /etc/letsencrypt/live/sso.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/sso.example.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置:
```bash
sudo ln -s /etc/nginx/sites-available/nexus-id /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 4. 使用systemd管理服务

创建服务文件 `/etc/systemd/system/nexus-id.service`:

```ini
[Unit]
Description=SSO Platform API Server
After=network.target mysql.service redis.service

[Service]
Type=simple
User=sso
WorkingDirectory=/opt/nexus-id
Environment="SSO_ENV=production"
ExecStart=/opt/nexus-id/bin/server
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动服务:
```bash
sudo systemctl daemon-reload
sudo systemctl enable nexus-id
sudo systemctl start nexus-id
sudo systemctl status nexus-id
```

### 5. 数据库优化

#### MySQL配置优化
```ini
# /etc/mysql/mysql.conf.d/mysqld.cnf
[mysqld]
max_connections = 500
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
query_cache_size = 128M
slow_query_log = 1
long_query_time = 2
```

#### 定期备份
```bash
#!/bin/bash
# /opt/scripts/backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/opt/backups"
MYSQL_USER="root"
MYSQL_PASS="password"

# 备份数据库
mysqldump -u$MYSQL_USER -p$MYSQL_PASS sso_platform | gzip > $BACKUP_DIR/sso_$DATE.sql.gz

# 保留最近30天的备份
find $BACKUP_DIR -name "sso_*.sql.gz" -mtime +30 -delete
```

添加到crontab:
```bash
# 每天凌晨2点备份
0 2 * * * /opt/scripts/backup.sh
```

## 🚨 故障排查

### 常见问题

#### 1. 数据库连接失败
```bash
# 检查MySQL状态
systemctl status mysql

# 检查连接
mysql -u sso_user -p -h localhost

# 查看错误日志
tail -f /var/log/nexus-id/app.log
```

#### 2. Redis连接失败
```bash
# 检查Redis状态
systemctl status redis

# 测试连接
redis-cli ping

# 查看Redis日志
tail -f /var/log/redis/redis-server.log
```

#### 3. Token验证失败
- 检查JWT_SECRET是否一致
- 确认token未过期
- 检查token是否在黑名单中

#### 4. 性能问题
```bash
# 查看慢查询
mysql> SHOW FULL PROCESSLIST;

# 查看Redis命中率
redis-cli info stats

# 查看应用goroutines
curl http://localhost:8080/debug/pprof/goroutine?debug=1
```

## 🔐 安全加固

### 防火墙配置
```bash
# UFW
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# 只允许本地访问MySQL和Redis
sudo ufw deny 3306
sudo ufw deny 6379
```

### fail2ban配置
```ini
# /etc/fail2ban/jail.local
[ssod-auth]
enabled = true
port = http,https
filter = ssod-auth
logpath = /var/log/nexus-id/app.log
maxretry = 5
findtime = 600
bantime = 3600
```
