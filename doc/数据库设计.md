# 数据库设计

## 📊 核心表结构

### users (用户表)

```sql
CREATE TABLE users (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    tenant_id BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '租户ID，0为默认全局租户',
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    avatar VARCHAR(255),
    status TINYINT DEFAULT 1 COMMENT '1:active, 0:disabled',
    email_verified BOOLEAN DEFAULT FALSE,
    deleted_at BIGINT UNSIGNED DEFAULT 0 COMMENT '软删除时间戳，0表示未删除。解决唯一索引冲突',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_tenant_email_deleted (tenant_id, email, deleted_at),
    UNIQUE KEY uk_tenant_username_deleted (tenant_id, username, deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### clients (客户端应用表)

```sql
CREATE TABLE clients (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    tenant_id BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '关联租户ID',
    client_id VARCHAR(64) NOT NULL COMMENT 'OIDC client ID',
    client_secret_hash VARCHAR(255) NOT NULL COMMENT '必须Hash存储',
    name VARCHAR(100) NOT NULL,
    redirect_uris JSON NOT NULL COMMENT '允许的回调地址',
    scopes JSON COMMENT '允许的权限范围',
    grant_types JSON COMMENT '授权类型',
    response_types JSON COMMENT '响应类型',
    logo_url VARCHAR(255),
    description TEXT,
    is_public BOOLEAN DEFAULT FALSE COMMENT '是否为公共客户端',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_client_id (client_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### roles (身份/角色表)
*注：SSO 仅维护全局身份/群体属性，不负责子系统具体的读写操作权限拦截。*

```sql
CREATE TABLE roles (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    tenant_id BIGINT UNSIGNED NOT NULL DEFAULT 0,
    name VARCHAR(50) NOT NULL,
    code VARCHAR(50) NOT NULL,
    description VARCHAR(255),
    status TINYINT DEFAULT 1,
    deleted_at BIGINT UNSIGNED DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_tenant_code_deleted (tenant_id, code, deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### user_roles (用户角色关联表)

```sql
CREATE TABLE user_roles (
    user_id BIGINT UNSIGNED NOT NULL,
    role_id BIGINT UNSIGNED NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (user_id, role_id),
    INDEX idx_role (role_id)
    -- 注意：不使用外键约束，依靠应用层保证最终一致性，提升并发性能和伸缩性
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### authorization_codes (授权码表)

```sql
CREATE TABLE authorization_codes (
    code VARCHAR(255) PRIMARY KEY,
    client_id VARCHAR(64) NOT NULL,
    user_id BIGINT UNSIGNED NOT NULL,
    redirect_uri VARCHAR(255) NOT NULL,
    scope VARCHAR(500),
    expires_at DATETIME NOT NULL,
    code_challenge VARCHAR(255) COMMENT 'PKCE',
    code_challenge_method VARCHAR(10),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_client_user (client_id, user_id),
    INDEX idx_expires (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### refresh_tokens (刷新令牌表)

```sql
CREATE TABLE refresh_tokens (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    token_hash VARCHAR(255) UNIQUE NOT NULL,
    user_id BIGINT UNSIGNED NOT NULL,
    client_id VARCHAR(64) NOT NULL,
    scope VARCHAR(500),
    expires_at DATETIME NOT NULL,
    revoked_at DATETIME NULL COMMENT '令牌轮换或注销时置位标志',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_client (user_id, client_id),
    INDEX idx_expires (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### audit_logs (审计日志表)

```sql
CREATE TABLE audit_logs (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    tenant_id BIGINT UNSIGNED DEFAULT 0,
    user_id BIGINT UNSIGNED,
    action VARCHAR(100) NOT NULL COMMENT '操作类型',
    resource VARCHAR(100) COMMENT '操作对象',
    details JSON COMMENT '详细信息',
    ip_address VARCHAR(45),
    user_agent TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_tenant_user (tenant_id, user_id),
    INDEX idx_action (action),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 📝 索引设计

### 性能优化索引
- `users.email` / `users.username` 组合 `tenant_id` 和 `deleted_at` 验证唯一性。
- `clients.client_id` - OIDC客户端查找。
- `authorization_codes.expires_at` - 配合定时任务清理过期授权码。
- `refresh_tokens.expires_at` - Token定期清理。
- `audit_logs.created_at` - 配合数据定期归档与分区查询。

## 🔐 架构与安全考虑

1. **密码存储**: 使用 `bcrypt` 加密，cost >= 10。
2. **敏感字段**: `client_secret` 严格要求哈希存储，避免数据库拖库后导致的所有客户端越权。
3. **软删除陷阱修复**: 采用 `deleted_at`（Unix时间戳）代替 `status: -1` 做逻辑删除标记，并将其加入复合唯一索引。彻底解决同名/同邮箱账户重新注册时产生的 MySQL Duplicate key 报错。
4. **彻底移除物理外键**: 在互联网高并发架构中弃用级联物理外键（`DELETE CASCADE`），防止大量更新并发时触发死锁，并为未来的分表分库（Sharding）铺路。业务层面采用逻辑删除或最终一致性清理。
5. **多租户基石**: `tenant_id` 早期介入主核心业务表，预留 SaaS 化扩展空间。
